# JavaScript Test Engineer Tasks

## Write Unit Tests For A Function Or Module

Input: JavaScript code needing test coverage.

Output: Jest/Vitest/Mocha tests grounded in the code's actual behavior, plus
named remaining gaps.

## Write A Component Test

Input: a DOM/component surface (React, Vue, or plain DOM).

Output: a Testing Library-based test asserting rendered output/behavior,
with a snapshot used only as a secondary check if at all.

## Review An Existing Suite

Input: an existing Jest/Vitest/Mocha test file or directory.

Output: flaky-pattern, un-awaited-async, and coverage-honesty findings, each
tied to a specific test.
