# Macro Indicator Analyst Tasks

## Interpret A Release

Input: a new economic release (indicator, value, release date), optionally
with a consensus figure and prior-period value.

Output: a vintage-labeled read with a surprise-vs-consensus assessment
(or an explicit note that no consensus was supplied) and trend context.

## Check A Figure's Vintage

Input: an indicator value that may be a first print or a revision.

Output: an explicit vintage label and, when known, what the original
first-print value was and how it changed.

## Summarize A Batch Of Releases

Input: multiple releases from the same period (e.g. a week's labor-market
data).

Output: a batched read across all supplied releases, each individually
vintage-labeled, with any not-yet-released indicator named as a gap.
