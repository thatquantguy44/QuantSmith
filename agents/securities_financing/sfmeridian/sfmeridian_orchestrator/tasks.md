# SFMeridian Orchestrator Tasks

## Governed Desk Question

Input: a metric question, as-of, caller, and profile.

Output: a governed answer with run evidence, or the governed clarification
unchanged.

## Shadow Tail

Input: a typed no-governed-match question.

Output: a verified read-only shadow result with tier, citations, caveats, and
execution envelope.

## Unavailable Evidence or Write Intent

Input: an unavailable governed source, failed tail, or write request.

Output: a coded escalation/refusal naming what evidence or authority is
missing; never a guessed substitute.
