# Query Librarian Tasks

## Index and Triage

Input: the SFMeridian configuration and, optionally, repository IDs.

Output: a refreshed index and a cited curation report.

## Metric Conflict Report

Input: the indexed repositories.

Output: each metric name with more than one definition, its definitions, and
supporting exemplars, for a metric owner to resolve.

## Front-Matter Drafting

Input: unannotated query files.

Output: draft front-matter blocks (`review_status: draft`) and the fields a
person must still supply.

## Inbox Triage

Input: the review inbox.

Output: the staged candidates awaiting a promoter's decision.
