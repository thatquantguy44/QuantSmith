# Status Roll-Up Tasks

## Gather Activity

Input: a description or log of the period's commits, notebooks, meeting
decisions, and results.

Output: a normalized activity list, with gaps or ambiguity flagged.

## Draft the Update

Input: the activity list, plus `role_context.yml` if present.

Output: a draft status update (`What Happened` / `What's Next` / `Blocked`),
labeled as a draft.
