# Demo Narrative Packager Tasks

## Draft the Narrative

Input: a prototype's actual results (metrics, charts, findings).

Output: a situation → insight → recommendation narrative grounded only in
supplied results.

## Draft the One-Pager

Input: the narrative above.

Output: a one-pager summary suitable for the target audience.

## Disclose Synthetic Data

Input: any visual or chart used in the narrative.

Output: an explicit note on any synthetic/illustrative data it contains,
per `instructions/data_provenance.md`.
