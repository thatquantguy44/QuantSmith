# Tough-Question Rehearsal Tasks

## Draft Persona Questions

Input: demo material (narrative, one-pager, results), optionally scoped by
`role_context.yml`'s stakeholder personas.

Output: skeptical, persona-appropriate questions grouped by persona.

## Draft Suggested Answers

Input: the questions above and the same demo material.

Output: a suggested answer per question, or an explicit "not yet
answerable" flag with what's missing.

## Assemble the Prep Sheet

Input: the questions and answers above.

Output: a concise, scannable prep sheet grouped by persona.
